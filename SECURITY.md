# Politique de sécurité / Security policy

Les correctifs de sécurité sont fournis pour la dernière release publiée.
Security fixes are provided for the latest published release.

Ne publiez pas de vulnérabilité dans une issue. Utilisez le formulaire privé
[Signaler une vulnérabilité](https://github.com/Institut-du-Numerique-Responsable/green-claude/security/advisories/new).

Do not disclose vulnerabilities in public issues. Use the private
[security advisory form](https://github.com/Institut-du-Numerique-Responsable/green-claude/security/advisories/new).

Indiquez la version, le scénario d'exploitation, l'impact, les étapes de
reproduction et, si possible, une correction proposée. Les mainteneurs visent
un accusé de réception sous sept jours. Merci de laisser le temps de préparer
et publier un correctif avant toute divulgation publique coordonnée.

Include the version, exploitation scenario, impact, reproduction steps and, if
possible, a proposed fix. Maintainers aim to acknowledge reports within seven
days. Please allow time for a coordinated fix before public disclosure.
