# Support

- Question d'utilisation : ouvrez une [discussion](https://github.com/Institut-du-Numerique-Responsable/green-claude/discussions).
- Bug reproductible : utilisez le formulaire « Bug » dans les issues.
- Faux positif d'audit : utilisez le formulaire « Faux positif ».
- Nouvelle règle : utilisez le formulaire « Nouvelle règle ».
- Vulnérabilité : suivez exclusivement la procédure privée de [SECURITY.md](SECURITY.md).

Merci d'indiquer la version de Green Claude, le système, la version de Bash et
de `jq`, ainsi qu'un exemple minimal reproductible.
