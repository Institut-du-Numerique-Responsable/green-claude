# Gouvernance

Green Claude est maintenu au sein de l'Institut du Numérique Responsable.

## Responsabilités

Les mainteneurs qualifient les issues, examinent les contributions, protègent
les informations de sécurité et publient les releases. Les propriétaires de
code sont `@gridboy` et `@robintra`.

## Décisions

Les décisions se prennent d'abord par consensus documenté dans une issue ou une
pull request. En cas de désaccord persistant, les propriétaires de code
tranchent en recherchant la solution la plus cohérente avec la mission de l'INR,
les référentiels cités et la maintenabilité du projet.

Toute modification de `main` passe par une pull request, une CI réussie et au
moins une approbation. Les mainteneurs autorisés créent les releases selon
[CONTRIBUTING.md](CONTRIBUTING.md). Un mainteneur durablement inactif peut être
retiré de `CODEOWNERS` par une pull request approuvée par l'autre propriétaire et
un représentant de l'INR.
